プライバシーポリシー

家事貢献記録bot（以下「本Bot」）のプライバシーポリシーです。

⚠️ 重要なお知らせ

本BotはLINE公式ではなく、個人が提供する非公式サービスです。

1. 取得する情報

本Botは、以下の情報を取得・保存します。

  • LINEのユーザーID
  • 参加しているグループのID
  • 記録された家事タスクやポイント情報
  • タスク実行時のメッセージ内容（タスク名、ポイント、メモなど）

2. 利用目的

取得した情報は、以下の目的で利用します。

  • 家事貢献ポイントの集計・ランキング表示
  • タスク定義の管理と表示
  • 不具合対応・改善のためのログ解析
  • サービス品質の向上

3. 第三者提供

原則として、取得した情報を第三者に提供することはありません。 ただし、以下の場合は除きます。

  • 法令に基づく場合
  • 裁判所、警察等の公的機関から要請があった場合
  • ユーザーの同意がある場合

4. 外部サービス利用

本Botは、以下の外部サービスを利用しています。

  • データベース・ホスティング：クラウドサービス（Supabase、Render等）
  • メッセージングプラットフォーム：LINE Messaging API

これらのサービスは、それぞれのプライバシーポリシーに従ってデータを処理します。

5. データの保存期間

取得した情報は、以下の期間保存されます。

  • グループに参加している間：サービス提供のために必要な期間
  • グループ退会後：一定期間はログ保持（不具合対応のため）
  • 削除依頼があった場合：合理的な期間内に削除対応いたします

6. ユーザーの権利

ユーザーは、以下の権利を有します。

  • 個人情報の開示請求
  • 個人情報の訂正・削除請求
  • データの削除依頼

これらの請求・依頼については、お問い合わせ窓口までご連絡ください。

7. お問い合わせ窓口

本ポリシーに関するお問い合わせ、またはデータ削除のご依頼は、以下の窓口までお願いいたします。

  • GitHub Issues

8. ポリシーの変更

本ポリシーは、法令の変更やサービスの改善に伴い、予告なく変更する場合があります。 変更時は、このページで告知いたします。
