@家事貢献記録bot コマンド一覧

LINE Botで使用できるコマンドの一覧です。

基本的な使い方

@家事貢献記録bot 家事報告
登録されているタスク名を入力すると、その家事を報告できます。タスク名の後にメモを追加することもできます。タスク名はかな/英語/タイプミス1文字まで自動補正されます。
例: @家事貢献記録bot 皿洗い または @家事貢献記録bot 皿洗い 15分
@家事貢献記録bot me
今週の自分のポイントと内訳を表示します。
例: @家事貢献記録bot me
@家事貢献記録bot top
今週のグループ内ポイントランキングを表示します。
例: @家事貢献記録bot top
@家事貢献記録bot 取消
別名: 取り消し, キャンセル, cancel
直前の報告を取り消します。
例: @家事貢献記録bot 取消

タスク管理

@家事貢献記録bot task
別名: tasks
登録されているタスク一覧とポイントを表示します。
例: @家事貢献記録bot task
@家事貢献記録bot add
新しいタスクを追加します。
使い方: @家事貢献記録bot add タスク名 ポイント
例: @家事貢献記録bot add 掃除機がけ 150
@家事貢献記録bot delete
登録されているタスクを削除します。登録されているタスク名と同じ表記のときだけ削除できます。
使い方: @家事貢献記録bot delete タスク名
例: @家事貢献記録bot delete 掃除機がけ

一時タスク

✨ @家事貢献記録bot temp
一時タスクでポイントを追加します。タスク登録不要で、その場でポイントを追加できます。
使い方: @家事貢献記録bot temp タスク名 ポイント
例: @家事貢献記録bot temp 買い物 100

ヘルプ

@家事貢献記録bot help
このコマンド一覧をLINE上で表示します。
例: @家事貢献記録bot help
💡 便利な機能
  • タスク名はかな/英語/タイプミス1文字まで自動補正されます
  • 家事報告時にメモを追加できます（例: @家事貢献記録bot 皿洗い 15分）
  • タスク名の大文字小文字は区別されません
